# Reporte gerencial

## Proyecto
**TorneoJAV — Gestor de Torneos de Fútbol Amateur**

## Objetivo
Desarrollar una aplicación que centralice la gestión de equipos, jugadores, calendarios, resultados y posiciones.

## Estado actual
Se encuentran definidos el problema, propuesta de valor, Lean Canvas, stakeholders, roles del equipo, roles del sistema y stack tecnológico inicial.

## Avances
- Problema identificado.
- Lean Canvas elaborado.
- Stakeholders identificados.
- Roles del equipo definidos.
- Roles de usuario definidos.
- Tecnologías iniciales seleccionadas.
- Próximos incrementos definidos.

## Pendientes
- SRS completo.
- Historias de usuario.
- Casos de uso.
- Modelo ER.
- Arquitectura.
- Wireframes.
- Autenticación.
- Gestión de equipos.
- Torneos y calendario.
- Resultados y estadísticas.
- Pruebas.

## Riesgos

| Riesgo | Impacto | Mitigación |
|---|---|---|
| Retrasos | Alto | Dividir trabajo por Sprint |
| Problemas de integración | Alto | Integrar cambios frecuentemente |
| Errores en fixture | Alto | Crear pruebas específicas |
| Cambios de requisitos | Medio | Mantener backlog actualizado |
| Conflictos Git | Medio | Ramas y commits frecuentes |
