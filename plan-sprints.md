# Plan inicial de Sprints

## Sprint 1 — Análisis y diseño
**Objetivo:** definir qué debe hacer TorneoJAV.

- Requisitos
- Historias de usuario
- Casos de uso
- Requisitos no funcionales
- Modelo ER inicial
- Arquitectura inicial
- Wireframes

**Resultado:** documentación inicial lista para desarrollo.

## Sprint 2 — Usuarios y equipos
**Objetivo:** permitir autenticación y gestión de equipos.

- Login
- Roles
- Usuarios
- Equipos
- Jugadores

**Resultado:** gestión básica de usuarios y equipos.

## Sprint 3 — Torneos y partidos
**Objetivo:** crear torneos y generar partidos.

- Crear torneo
- Configurar formato
- Equipos participantes
- Fixture
- Calendario
- Partidos

**Resultado:** torneo con calendario generado.

## Sprint 4 — Resultados y estadísticas
**Objetivo:** cerrar el ciclo de operación.

- Resultados
- Goles
- Tarjetas
- Actas
- Posiciones
- Estadísticas
- Integración

**Resultado:** flujo completo del torneo.
