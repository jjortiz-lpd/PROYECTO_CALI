# Requisitos no funcionales

Estos requisitos son una definición inicial derivada de las necesidades expresadas en las HU. No se agregan métricas que no estén especificadas.

| ID | Categoría | Requisito |
|---|---|---|
| RNF-01 | Seguridad | El sistema debe controlar el acceso de acuerdo con el rol autenticado. |
| RNF-02 | Integridad | La información mostrada debe corresponder con la información almacenada. |
| RNF-03 | Persistencia | Los cambios indicados como persistentes deben conservarse. |
| RNF-04 | Usabilidad | Los mensajes de error y validación deben ser comprensibles. |
| RNF-05 | Mantenibilidad | El sistema debe mantener componentes organizados para facilitar cambios. |
| RNF-06 | Control de acceso | La información restringida no debe estar disponible a usuarios sin permisos. |
