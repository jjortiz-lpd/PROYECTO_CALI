# Casos de uso

## Actores

- Administrador de liga
- Capitán de equipo
- Árbitro / anotador

## Casos principales

| ID | Caso de uso | Actor |
|---|---|---|
| CU-01 | Iniciar sesión | Todos |
| CU-02 | Gestionar usuarios | Administrador |
| CU-03 | Crear torneo | Administrador |
| CU-04 | Configurar torneo | Administrador |
| CU-05 | Aprobar equipo | Administrador |
| CU-06 | Registrar equipo | Capitán |
| CU-07 | Gestionar jugadores | Capitán |
| CU-08 | Consultar calendario | Capitán |
| CU-09 | Consultar posiciones | Capitán |
| CU-10 | Registrar resultado | Árbitro |
| CU-11 | Registrar eventos | Árbitro |
| CU-12 | Cerrar acta | Árbitro |
| CU-13 | Consultar estadísticas | Usuarios autorizados |

## Flujo general

1. El capitán registra su equipo.
2. El administrador revisa y aprueba la inscripción.
3. El administrador crea/configura el torneo.
4. El sistema genera el calendario.
5. El árbitro registra los resultados y eventos.
6. El sistema actualiza las posiciones.
7. Los usuarios consultan calendario, resultados y posiciones.
